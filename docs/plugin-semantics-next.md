# Remaining public plugin semantics

This audit compares the current adapters with pinned server `ddd65fc`. A compiled export or registered callback is not a passed parity gate. [public-plugin-coverage.json](public-plugin-coverage.json) retains unverified statuses until native fixtures establish each behavior.

The current DLL fixture and gated GSC bootstrap exercise actual native registration, global/entity usercall, frame/tick callbacks and asynchronous completion. Run the GSC checks with `khz_plugin_tests=1`, loading the regression DLL before compiling the map. Check both global and connected-entity success records. Separately exercise command permission, disable/unload, imports, cached script thunks, and map/restart barriers. [header_smoke.c](../sdk/tests/header_smoke.c) should compile as both MSVC C and C++ with `/Gd`; the marker must use a C-linkage block in C++ and a definition without storage `extern` in C because `extern` combined with `dllexport` and `selectany` causes MSVC C2496.

The SDK census now records the exact case-sensitive union of active entries in `plugins/function_declarations.h`, `src/asmsource/pluginexports.asm`, and all `P_P_F` definitions: **192 exports**, from 172 declarations, 111 assembly names and 74 definitions. [update-plugin-census.ps1](../scripts/update-plugin-census.ps1) regenerates source/line evidence and checks previously omitted names. It includes live exports such as `Plugin_FS_FreeFile`, `Plugin_Scr_AllocArray`, `Plugin_unzSetPassword`, `Plugin_IsLoaded`, `Plugin_GetVersion`, active address aliases and `PHandler_Error`. `Plugin_GetPlayerUid` and legacy `Plugin_GetPlayerUID` are distinct exports. Some deprecated identifier exports deliberately return no data upstream; record that disposition separately from useful capability parity. Do not count a named stub as implementation evidence.

The next isolated increment is stats wrappers and safe native/cross-plugin command removal, followed by files, HTTP, sockets and thread compatibility as separate service modules with explicit ownership, independently compiled SDK fixtures and short native endpoint tests. Existing source changes above remain unverified until the engine, pure fixtures and native cases pass. All require performance checks with their enabled callbacks; arbitrary native plugin computation can still violate a millisecond deadline.

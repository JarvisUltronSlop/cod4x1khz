# Native server Collision checkpoint

The three source-owned provider fragments and native entry guards are implemented behind `COD4X1KHZ_SERVER_CHECKPOINT && COD4X1KHZ && KISAK_MP && KISAK_DEDICATED`. The flag is absent in ordinary builds. Build 68 source staging compiled all 54 native translation units with the flag both off and on, with no duplicate strong symbols ([on log](../results/checkpoint-staging-on68.log), [off log](../results/checkpoint-staging-off68.log)). This checks native declaration and source-scope integration. Provider registration, guard enrollment, map binding and the whole-coordinator fence still need owner integration and runtime capture/restore tests. It does not establish full-world replay correctness. All fourteen native domains remain mandatory; Collision strengthens its own requirement to parts 0, 1 and 2. Missing enrollment, an active trace, a foreign allocation or unsupported state refuses capture with a concrete diagnostic.

| Source-owned fragment | Actual live storage restored | Original map data pinned |
| --- | --- | --- |
| [load](../engine/src/khz/khz_server_collision_load_checkpoint.inl), end of `qcommon/cm_load.cpp` | `cm`, `g_traceThreadInfo[8]`, `g_box_brush[8]`, `g_box_model[8]`, the separate `cm.box_brush` template, and each initialized context's exact `int[cm.partitionCount]` allocation | Original clipmap pointer table/name/checksum; BSP planes/nodes/leaves, brush sides/edges/indices, cmodels, collision triangles/edge bits/borders/partitions/AABB trees, visibility and entity-string assets |
| [world](../engine/src/khz/khz_server_collision_world_checkpoint.inl), end of `qcommon/cm_world.cpp` | Entire native `cm_world` sector/free tree, `sv.svEntities[1024]`, and the exact loaded `cStaticModel_s[]` records, including mutable `writable.nextModelInWorldSector` links | Static-model transforms, original XModel pointers and actual collision-surface/triangle data |
| [query](../engine/src/khz/khz_server_collision_query_checkpoint.inl), end of `server/sv_world.cpp` | Native `actorLocationalMins`/`actorLocationalMaxs` | Original stationary brush entity identities, brush handles, bounds and transforms |

`World` part 0 already restores `g_entities`, `g_clients`, `level` and native BGS; its seven additional parts cover other native gameplay globals. `Network` also copies `sv`, including `svEntities`. Collision's independent copy is captured under the same fence and restored to the same original baseline; it explicitly advertises the linked collision span it restores. It does not replace the full World or Network providers. Immutable fingerprints detect changed map assets; they are not substitutes for restoring mutable storage.

Verified native seams explain the extra storage. `CM_GetTraceThreadInfo` increments a context's `checkcount.global`; `CM_TraceThroughAabbTree_r` and sight traversal write `checkcount.partitions`. `CM_TempBoxModel` changes the current TLS box brush/model. `CM_SortNode` rewrites both entity-sector links and static-model links. `SV_LinkEntity` writes cluster numbers, link bounds and solid/absolute entity bounds. `CM_BoxLeafnums` owns a stack `leafList_s` and caller-owned result array; there is no additional global leaf cache to invent. Native `CM_SaveWorld` saves only tree/free-list data and therefore cannot implement this checkpoint by itself.

The real MP trace contexts initialized by `CM_InitAllThreadData` are 0–3 and 7. Slots 4–6 must have no CM scratch. Each initialized partition pointer must remain its original Hunk allocation, each TLS box pointer must refer to its original `g_box_*[context]`, and every native trace TLS binding must stay unchanged. The binder atomically replaces one Collision map-range set using `KHZ_ServerCheckpointReplaceMapRanges`: only the exact partition arrays, box template and static-model record allocation are advertised. Native map/scratch lifecycle entries retire that set through `KHZ_ServerCollisionInvalidateMapBinding` before changing the allocation lifetime. A completed new map needs a fresh bind. Static BSS spans and other domains' map ranges remain separate. No surrounding Hunk or DB zone is claimed as restored. BSP/leaf/triangle/AABB indices and pointer-bearing leaf brush lists are validated and their exact immutable source spans fingerprinted.

Integration requires a real query fence before the first of all fourteen provider captures. The paused owner calls `KHZ_ServerCollisionFenceEnter` before `Coordinator::capture`; validation/restore retains that fence. Release it only after the coordinator is empty/discarded, including an early refused capture which never reached Collision. Gate publication, counter entry, gate recheck, counter exit and the capture counter scan use sequentially consistent atomics. Their single total order means an admitted query stays visible until completion, or its recheck sees the fence and refuses all native work. Before-effect lifecycle/mutation entries participate in those counters too. Capture refuses any nonzero counter rather than waiting. Foreign attempts latch a saturating atomic counter/reason; only the actual main owner converts those diagnostics into `KHZ_ServerCheckpointRejectExternalEffect`, whose implementation asserts main-thread ownership. A refusal between arming the fence and starting coordinator capture is retained and rejects capture. Baseline restore may still clean up an ineligible branch.

Enrollment is separate and mandatory: `KHZ_ServerCollisionEnrollQueryHooks(7)` is permitted only after the corresponding real native entry guards are installed and reviewed. Registration or inclusion alone cannot enroll guards. `KHZ_ServerCollisionQueryScope(group)` must wrap the entry before its first native read/write; callers must handle `!allowed()` conservatively. Native engine longjmp cleanup must call `KHZ_ServerCollisionErrorCleanup` after aborting the main query stack; it never clears another owner's counters.

The required guard groups are:

- CM scratch: `cm_trace.cpp` guards the trace/sight/transformed entries, TLS getters and box/model accessors; `cm_test.cpp` guards leaf/PVS/contents queries. `cm_mesh.cpp` guards the direct AABB/leaf entries and recursive partition-stamp writers. Pure arithmetic helpers need no independent mutable storage; remaining internal walks stay inside their enclosing native query.
- CM world: `CM_AreaEntities`, `CM_PointTraceStaticModels`, `CM_PointTraceStaticModelsComplete`, `CM_ClipMoveToEntities`, `CM_ClipSightTraceToEntities`, `CM_PointTraceToEntities`, `CM_PointSightTraceToEntities`, and native entity link/unlink/sector-sort entrypoints. Direct static-model queries in `cm_staticmodel.cpp` also have scopes. All recursive walks remain inside the outer scope.
- SV world: `SV_LinkEntity`, `SV_UnlinkEntity`, `SV_Trace`, `SV_TracePassed`, `SV_SightTrace`, `SV_SightTraceToEntity` and `SV_PointContents`, including any direct per-entity entry which can be invoked independently. `SV_LinkEntity` additionally calls `KHZ_ServerCollisionAllowEntityLink` before changing solid/SnapAngles/bounds.

Installed before-effect hooks cover CM load/shutdown/unload/init and object/fastfile map entrypoints; world/static-model initialization; direct collision debug/winding builders; and native DynEntity sector creation/link/unlink, client initialization/process/shutdown, trace, damage/event and physics-creation entrypoints. DynEntity work is refused while pinned. The observer must still require database/render/worker asset owners actually parked and enforce the other domains' BSP/DB/Hunk lifetime barriers; fingerprints or empty counters do not establish that barrier. Pointer-returning CM accessors return null on refusal; foreign callers do not acquire an ownership grant for a retained native pointer. Native users must remain within the guarded outer query and actual parked-owner lifecycle.

`G_SetOrigin`, `G_SetAngle`, `G_SetFixedLink`, `G_GeneralLink`, the MP `SV_SetBrushModel`, early `G_FreeEntity`/delayed/event deletion, and the actual mover/script trajectory setters now guard stationary brush changes before mutation. Tagged brush capture is refused; `G_RunMover` refuses a tagged or moving brush dispatch. Script move/rotation/vibration/solid commands and physics launch cannot silently change unsupported geometry. An unchanged original stationary brush may relink; moving/new/replaced brush geometry is deliberately refused until its full ownership is supported. Non-brush players/items/missiles may change their restored entity and sector records, subject to every other mandatory domain. Map/game initialization outside a pinned fixture keeps native behavior.

Supported-state diagnostics remain conservative. Mutable native DynEntity pose/client/collision arenas, nonzero actual `dynEntCollWorlds[2]`, external physics objects and vehicles/helicopters/planes are rejected. Definition-only DynEntity assets are pinned and not treated as a restored runtime arena. Client-only DynEntity pieces/visual state has no Collision provider; the dedicated observer must exclude all such client owners. Debug `windingPool` is not advertised as restored and its builders are refused while pinned. Geometry spans have a 16 MiB individual bound and 128 MiB fingerprint-work bound per component; static records are capped at 65,535, trace partitions at 262,144 and unique static collision model assets at 4,096. Oversized/unreadable maps fail explicitly. Images allocate only during an explicit paused capture and free during discard. Restore performs fixed copies into original spans without relinking, allocation, refcount callbacks or script/gameplay calls.

Next validation must compile all three native scope wrappers, prove enrollment refuses an omitted guard group, and run actual same-map capture/branch/restore with byte changes in every advertised mutable span. Exercise trace global/partition stamps, TLS boxes, sector allocation/freeing, player links, PVS clusters and static-model link rewrites. Refuse active/foreign traces, replaced map/TLS pointers, changed loaded geometry, native DynEntity/physics state and a moving brush before side effects. Verify atomic map-range replacement across discard/map changes and longjmp cleanup. Only after the remaining thirteen domains and transport fence pass actual branch replay may the full-world replay gate advance.

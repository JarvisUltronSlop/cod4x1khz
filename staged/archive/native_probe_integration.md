# Staged native codec probe integration

The implementation is staged and has not been linked into the game or run on a loaded map. Its isolated original-TU object compilation passed with `python staged/archive/run_contracts.py --probe-typecheck-only`; final evidence including both object hashes is `results/20261003-124844-371109/result.json`. The earlier missing `scrVarPub` declaration failure remains in its original directory; including the actual `script/scr_main.h` fixed it. Object compilation is not runtime cleanup or codec proof.

The separate retargeted synthetic adapter test compiles the actual production `engine/src/khz/khz_archive.cpp` with native layouts and synthetic owner/current-state/decoder/error dependencies. It passed 7 groups and 131,568 comparisons. `results/20261003-124212-841367/result.json` identifies the production source, stable policy/header inputs and executable hash. Native codec, loaded-map and world-replay attestations in that result remain false.

## Source placement and exact hooks

Copy `native_probe.h`, `native_probe.inl` and `native_probe_profile.inl` into one engine source include directory, retaining their relative header name or consistently renaming all three include references. The natural final names are `khz/khz_archive_probe.h`, `khz/khz_archive_probe.inl` and `khz/khz_archive_probe_profile.inl`.

1. At **EOF `khz_archive.cpp`**, under `COD4X1KHZ && KISAK_MP && KISAK_DEDICATED`, include the probe fragment. It accesses the original private `archivePolicy`; do not move the policy into a generic writable global or instantiate a second sidecar.
2. At **EOF `server_mp/sv_snapshot_profile_mp.cpp`**, under the same guard, include the profiler fragment. It captures/restores its actual declared symbols, including private `s_avgSnapshotSize`. It does not require any ALL14 provider or coordinator to be enabled.
3. At the **first main-owner entry of `SV_Shutdown`**, before `Com_SyncThreads`, `SV_FinalMessage`, `SV_ShutdownGameProgs` or any state/arena/map release, call `KHZ_ArchiveProbeAbortBeforeServerShutdown()` under that guard. This is mandatory native longjmp cleanup. It restores/frees only an active probe image, and is otherwise a no-op. Do not place it after `SV_ClearServer`, `SV_ShutdownGameProgs` or `KHZ_ArchiveShutdownComplete`.
4. Include the declaration in the dedicated runtime/private command adapter. Register a source-owned boundary callback through `KHZ_ArchiveProbeInstallBoundary(callback)` before exposing the runner. Missing callback fails closed.
5. A private authenticated benchmark/test-controls command calls `KHZ_ArchiveRunCodecProbe()` synchronously and returns `KHZ_ArchiveCodecProbeJSON()`. Do not call it from steady ticks, scripts, a service worker, or an arbitrary plugin. Do not extend ordinary `khz_json` statistics reads to execute it implicitly.

The existing adapter source already belongs to both custom multiplayer targets; these guarded EOF includes do not add a new independently compiled implementation TU. The client build has no probe calls/exports. Windows heap APIs use the existing system linkage. Original-TU wrapper sources in this staging directory are for type checking only and must not be added to the game target, where they would duplicate existing native definitions.

The external callback is an actual code seam, not a restore attestation. It must inspect the authenticated control origin, source-owned loaded-plugin/service state, database/asset lifetime, fixed-tick completion, and any persistent world checkpoint pin. It must reject active web/content/screenshot work, a pending lifecycle transition or a foreign native worker callback. For a conservative first fixture, content workers that have ever been started can be rejected; a queue-empty check alone cannot prove a dequeued hashing job has finished. Do not use diagnostics substring matches as proof of a transfer's quiescence. This callback does not pump queues or invoke gameplay while checking readiness.

## Explicit cleanup and storage

The probe registers its exact `HeapAlloc` pointer before capture invokes native read helpers. An incomplete capture can be freed on an unexpected error without restoring uninitialized bytes. Both the bounded decoded-work allocation and complete codec/profile allocation finish before the first codec mutation. The complete image is validated against original storage before `backupReady` becomes true.

It saves all five codec arenas: 512 cache descriptors, 16,384 cached entities, 4,096 cached clients, 1,200 raw descriptors and all 32 MiB raw bytes. It saves six actual scalar clocks/counters, `svsHeader`/validity, actual archive message and 128 KiB temporary bytes, archiving flag, complete original private sidecar, actual `orderInfo`, and both `g_dummyHudCurrent`/`g_dummyHudCurrent_1` values. The native copy helpers currently only read those dummy HUD records; they are nevertheless included in the exact scope image.

The profile fragment uses one enumerated field list for member declaration, capture, restore and exact comparison. It includes packet modes/starts, all entity/PS/netfield bit arrays, snapshot size/compression/poll counters and all scalar scratch. Packet-data recording is disabled inside the branch, but the unconditional counters and `orderInfo` still require this backup.

Restore copies only original codec arrays/scalars and scratch to identical original allocations; there are no setters, callbacks, constructors or allocations in the native restore writes. A new capture of the restored source-owned profiler state occupies preallocated scratch. Every saved member is then compared exactly, and a diagnostic FNV-64 byte hash before/after covers the same scope. Exact byte equality is required in addition to the noncryptographic hash. Owned entity/client/PS sources and `level.time`/`previousTime` are observed read-only before/after; they are never restored.

The abort hook restores and frees both exact allocations before the original shutdown final messages execute. A session/map/entity-span/logical-tick/level-time mismatch refuses writes to a different lifetime, frees the image and marks cleanup failed. Do not catch/ignore the original error: normal native error/shutdown behavior continues. No deliberately corrupt payloads or expected `Com_Error` injections are in the first probe. A Tracy-enabled build refuses the probe because abandoned native zones would need separate unwind treatment.

Normal gameplay resumes only after the image has been completely restored and freed. Native elapsed scheduler debt is retained; no FPS or 1 kHz performance acceptance sample may overlap this deliberate synchronous diagnostic stall. The queued datagrams/control requests remain untouched until normal processing returns.

## What the probe actually executes

- It creates a temporary empty **codec-only** branch at the original archive epoch. It does not invoke map reset, alter script/gameplay time, move players, execute a script or restore a world.
- The native encoder reads the unchanged actual loaded world at controlled archive `svs.time` values. Full and delta messages are committed by the real production completion path, and native raw decoding is forced by cache invalidation.
- All actual serialized client/PS/entity fields from unchanged-world full/delta results are compared. Native quantized values are compared to decoded representations rather than raw live floating-point bytes. It independently serializes/decode each real live client and linked entity through native helper calls for the full-frame oracle, including native field definitions, PS stats/ammo/clips/objectives/HUD/weapon models and float-valued fields. Actual connected-client and archive-eligible linked-entity counts must match the decoded rows; each returned row must also belong to that actual source set.
- Actual production lookup runs at all 50 one-millisecond remainders: normal logical delay, oldest clamp and current fallback, for 150 cases.
- An actual 131,072-byte message is filled with bounded `MSG_WriteData` before a required full encode; its real writes overflow. The completion path leaves native cache progress intact and does not append a raw descriptor. A subsequent real encode reuses the id; old phantom time/base/cache identities must reject, and the new decoded payload must match the unchanged-world oracle.
- A real full-cache record is moved to the physically next metadata write slot and then to the 64-row client eviction edge. Each guard must refuse the borrowed frame and a native delta lookup must perform fresh full+delta decodes. Real serialized payloads are checked. The unchanged-world test does not claim to reproduce every dynamic client-addition alias pattern.
- Real encoded messages receive explicitly synthetic trailing padding to position bytes at `32 MiB - 64`. The next actual encoded record crosses the byte-ring boundary; real split-read decoding must match the oracle. An old cached full record cannot resurrect raw id0 after byte eviction.

## Result contract and remaining gates

The bounded JSON records actual session/tick/server id/native time, observed client/entity counts, full/delta/native decode counts, serialized/float comparisons, individual scenario flags, allocated/profile byte extents, exact cleanup, observed-world stability, diagnostic hashes and bounded escaped refusal text. It always states `full_world_restore=false` and `authoritative_replay=false`.

Loaded-map runtime passage and abort cleanup are still unverified. After integration, require a real loaded stock map, one human and 15 bots, each scenario flag true, meaningful decode/serialized/float counts, exact cleanup and observed world stability; preserve exact source/binary provenance. Live killcam/follow, death/respawn/admission interpolation, descriptor-capacity wrap, intentionally malformed codec error paths, custom hit-rewind history, all-domain replay and measured steady performance remain separate gates.

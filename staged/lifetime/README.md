# Staged native lifetime admission

Production is unchanged and `COD4X1KHZ_SERVER_CHECKPOINT` remains off. This is a guarded proposal for the remaining animation/DB/hunk writer fence, not native replay evidence.

The existing animation helpers return true for every foreign thread before checking `KHZ_ServerCheckpointPinned`. The existing hunk helper returns false for every foreign thread even without a checkpoint. Both are boolean checks, so their success does not prevent a capture racing an already admitted operation. A full-function lease must start before the first native pointer dereference or side effect and remain until the original function returns.

The reviewed fixed-storage policy has one sequentially consistent atomic closed/count word. Open admission admits native asynchronous callers without evaluating any owner/tree predicate, and has no arbitrary compare-exchange retry limit. Closure is published even if older leases are active. The observer cannot read provider storage or tree/asset/hunk identities until the word is exactly Closed. Closed entry refuses foreign callers before invoking the lazy eligibility callback. The actual owner may invoke that callback only when every remaining lease belongs to its own thread, so a pre-closure foreign asset unload cannot race the eligibility read. Only exact tree/node proofs are eligible during a branch; asset, tree-allocation lifetime, DB replacement and hunk operations remain forbidden.

Native wrappers must use real `GetCurrentThreadId` and private thread-local lease state. A caller-supplied main-thread flag or tree boolean is not an admissible proof. Lazy tree eligibility must resolve to the existing 72 provider-owned tree addresses and the identical bound native animation definition; it must not advertise the surrounding hunk. Node helpers must check the original 4,096-node arena, alignment/index, in-use metadata and the node's exact bound tree. An unbound source/destination in clone/transfer is unsupported. A DObj wrapper must defer `obj->tree` until its lazy actual-owner proof, and validate the DObj belongs to the concrete Graphs ranges.

Close this gate before hunk observation and before any of the fourteen provider capture/validate reads. Map tree binding also requires closed idle admission while the coordinator is Empty. Keep admission closed through every validate, commit and provider discard; a provider may never release it. After all provider cleanup and coordinator Empty, the original actual owner explicitly releases it. A refused capture that published closure retains that closure until the same explicit cleanup. Counts/rejections/abandoned-error counters are diagnostics outside restoration.

Only the actual `Com_Error` ERR_JMP path abandons leases, immediately before its native longjmp. Returning ERR_SCRIPT/ERR_LOCALIZATION notices and dedicated ERR_MAPLOADERRORSUMMARY retain their scopes. Generic lifetime cleanup must abandon the current thread's depth, including a database-thread jump, preserve all other thread leases and the closed bit, and advance the TLS epoch so skipped/stale destructors cannot later release new admissions. The separate staged Physics helper supports main-only Physics entries and has its own 17 source-extracted assertions; it is not a proof of asynchronous lifetime cleanup or an executed native Com_Error.

`DB_FindXAssetHeader` is not pure: the native return path marks `assetEntry->inuse=1` and calls reorder bookkeeping, while missing lookup can allocate defaults. A pinned read cannot silently use that path. Proposed supported lookups may return only a concrete existing, already-inuse native header under a typed database idle/reorder-disabled guard; missing/default/reorder cases must latch/refuse before locks, registry changes, allocation or I/O. Otherwise the DB mutable metadata needs an actual provider. Generated stream loaders, physical-memory lifetime and direct virtual-memory entrypoints must also be audited/enrolled before activation; top-level unload checks alone cannot fence an asynchronous load or an indirect free.

Pending deliverables are the exact native entry catalogue, unapplied native wrapper/observer proposal, source-backed negative controls and lazy-admission concurrency/error contracts. Compilation/linking plus real closed-branch mutation/refusal and ALL14 restore tests remain required. No domain masks or provider requirements are reduced.
